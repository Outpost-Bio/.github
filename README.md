## How Waypoint compares
On Compass tasks above ~10k samples, Waypoint-170m matches or beats ridge regression and random forest baselines. Below that threshold, classical baselines remain competitive — Compass shows this openly; see compass-bench/LEADERBOARD-POLICY.md. External submissions are published within 30 days regardless of outcome.
